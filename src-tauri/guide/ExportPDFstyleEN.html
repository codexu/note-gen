PDF Export Style and Effect

Important Notes

  • Invoke browser export, pages are automatically set to A4 paper size and 15mm margins. Supported browsers: Edge, Chrome, Firefox, etc.
  • The MD file name is centered in the header, and page numbers are centered in the footer
  • All elements default to Noto fonts(also called Source Han fonts), with system fonts as fallbacks to ensure PDF export
  • Bold and italic effects for all element fonts in the MD editor can be rendered during export, but note:

    1. If the system does not have Noto Serif and STSong installed, bold and italic styles for Simplified Chinese in text, lists, and tables will revert to normal

    2. Level 1-3 headings are automatically bolded during export, so manual bolding in the MD editor is not recommended as it will stack

Heading Elements

Heading Font Family

Sans-serif: "Noto Sans SC/Noto Sans CJK SC", "Arial", "Meiryo", "Microsoft YaHei", sans-serif

  • Line Height: 1.5

Text and Typography Elements

Text Font Family

Serif: "Noto Serif SC/Noto Serif CJK SC", "Times New Roman", "STSong", "SimSun", serif

Paragraph

Style Properties:

  • Font Size: 12pt
  • Line Height: 1.5
  • First Line Indent: 2em
Blockquote

Style Properties:

  • Block Container: Dark gray left bar, light gray background
  • Font Size: 5% larger than body text
  • Padding: 1em top/bottom, 2rem left/right
  • Margin: 8pt top/bottom, 0 left/right
Links

Style Properties:

  • URL Display: Show URL after link text
  • URL Style: 90% font size, light gray
Horizontal Rule

Style Properties:

  • Margin: 1em top/bottom
  • Default Style: Horizontal line

List Font Family

Ordered List

Style Properties:

Tables and Images

Table Font Family

Same as text font family

Table

Style Properties:

  • Width: 100%
  • Cell Padding: 8px
  • Alignment: Horizontal and vertical center
  • Margin: 8pt top/bottom
  • Page Break Control: Avoid internal breaks
Image

Style Properties:
