Noto Fonts Installation Guide

Noto fonts have no commercial copyright risks and offer aesthetic appeal for both display and printing

Guide Description

Noto fonts (also called Source Han fonts) are free open-source fonts co-developed by Adobe and Google. These fonts perfectly support English, Chinese, Japanese and other characters, making them an ideal choice for design and development work. This guide will help you download and install high-quality Noto fonts from Google's GitHub repository.

Target fonts: NotoSansCJKsc-VF.otf and NotoSerifCJKsc-VF.otf
1

Access Google's GitHub Repository

Open your browser and access Google's GitHub repository:

https://github.com/notofonts/noto-cjk
2

Select Font Type

In the repository, you'll see two main folders:

  • Sans - Noto Sans
  • Serif - Noto Serif

Enter each of these folders respectively.

3

Download Font Files

In both Sans and Serif folders, navigate through two subdirectories to "Variable/OTF", then locate and download the target font files:

NotoSansCJKsc-VF.otf
NotoSerifCJKsc-VF.otf
4

Install Fonts on System

Locate the downloaded target fonts on your local machine (supports English and Simplified Chinese):

  • NotoSansCJKsc-VF.otf
  • NotoSerifCJKsc-VF.otf

Drag and drop them to the system fonts directory:

C:/Windows/Fonts

Japanese Font Installation Instructions

If you need to handle Japanese content, additionally install these Japanese font files:

Sans Japanese Font

NotoSansCJKjp-VF.otf

Sans-serif font containing Japanese glyphs

Serif Japanese Font

NotoSerifCJKjp-VF.otf

Serif font containing Japanese glyphs

Similarly drag and drop these files into the C:/Windows/Fonts directory to complete installation.

Installation Complete

After completing these steps, you have successfully installed Noto fonts. You can now use these fonts in any application that supports font selection.

Frequently Asked Questions

What's the difference between OTF and TTF formats?

OTF (OpenType Format) typically contains more advanced typographic features and supports more languages and special characters. TTF (TrueType Format) is more universal with better compatibility. This guide selects OTF format for optimal typographic results.

What are Variable Fonts (VF)?

Variable fonts integrate multiple variations of a font (such as different weights and widths) into a single file, allowing designers to adjust font properties via sliders. This provides greater design flexibility and reduces file quantity.

How to use these fonts in software after installation?

After installation, restart your design software (such as Adobe suite, Office, etc.), then search for "Noto Sans CJK SC" or "Noto Serif CJK SC" in the font list to use them.
